# XalgoExplorer

XalgoExplorer は、Windows から macOS へ移行するユーザーのための macOS ネイティブなファイルマネージャーです。

Windows で慣れた直接的なファイル操作を保ちながら、macOS らしいネイティブアプリとして使えることを目指しています。

## 主な特徴

- 複数のフォルダを同時に扱えるマルチペイン構成。
- 戻る、進む、上へ、更新、新規フォルダ、新規ファイル、切り取り、コピー、貼り付け。
- 同じディスクでは移動、別ディスクではコピーを基本とするドラッグ操作。
- よく使う場所、ユーザーショートカット、マウント済みディスク、ネットワーク場所をまとめるコンパクトなサイドバー。
- キーボード操作、クリック選択、範囲選択に対応。
- 多言語ラベルとツールチップ。
- macOS 用 DMG パッケージ。

## 候補版

`0.1.0-candidate` は Apple Silicon macOS 14 以降向けです。

GitHub Releases から DMG をダウンロードし、`xAlgo Explorer.app` を `Applications` にドラッグしてください。
