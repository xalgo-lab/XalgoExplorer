# XalgoExplorer

XalgoExplorer は、Windows から macOS へ移行するユーザーのための macOS ネイティブなファイルマネージャーです。

Windows で慣れた直接的なファイル操作を保ちながら、macOS らしいネイティブアプリとして使えることを目指しています。

## 主な特徴

- 複数のフォルダを同時に扱えるマルチペイン構成。
- 戻る、進む、上へ、更新、新規フォルダ、新規ファイル、切り取り、コピー、貼り付け。
- 同じディスクでは移動、別ディスクではコピーを基本とするドラッグ操作。
- よく使う場所、ユーザーショートカット、マウント済みディスク、ネットワーク場所をまとめるコンパクトなサイドバー。
- キーボード操作、クリック選択、範囲選択に対応。
- 多言語ラベルとツールチップ。
- macOS 用 DMG パッケージ。

## 候補版

`v0.1.1-candidate` は Apple Silicon macOS 14 以降向けです。

GitHub Releases から DMG をダウンロードし、`xAlgo Explorer.app` を `Applications` にドラッグしてください。

## バージョンノート

### v0.1.1-candidate

- キャンセルされた内部ドラッグの古い payload が残り、後続のドロップで別ファイルを誤って移動する問題を修正しました。
- `../file` や `a/b` のような危険なリネーム入力を拒否する検証を追加しました。
- 切り取り後に元のフォルダへ貼り付けた場合は no-op とし、重複ファイル名を作らないようにしました。
- Finder と相互に使えるシステムペーストボードのファイル URL コピー/貼り付けを追加しました。
- 検索欄に閉じるボタンと Escape 処理を追加し、フォーカス解除後に矢印キーでファイル一覧を操作できるようにしました。
- ハードコードされた偽のネットワーク機器を削除し、実際の検出が実装されるまでは空状態を表示します。
- 候補版メタデータ、DMG 名、README、回帰テストを更新しました。

### v0.1.0-candidate

macOS ネイティブのファイルマネージャー基盤、マルチペイン表示、ドラッグ操作、キーボード操作、多言語ツールチップ、Apple Silicon 向け署名済み DMG を含む初回公開候補版です。
