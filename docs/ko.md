# XalgoExplorer

XalgoExplorer는 Windows에서 macOS로 전환하는 사용자를 위한 macOS 네이티브 파일 관리자입니다.

Windows에서 익숙한 직접적인 파일 관리 방식을 유지하면서 macOS 환경에 자연스럽게 맞도록 설계되었습니다.

## 주요 기능

- 여러 폴더를 동시에 볼 수 있는 멀티 패널 작업 공간.
- 뒤로, 앞으로, 상위 폴더, 새로 고침, 새 폴더, 새 파일, 잘라내기, 복사, 붙여넣기.
- 같은 디스크에서는 이동, 다른 디스크에서는 복사를 기본으로 하는 드래그 앤 드롭.
- 홈 폴더, 사용자 바로가기, 마운트된 드라이브, 네트워크 위치를 담는 작은 사이드바.
- 키보드 탐색, 마우스 선택, 영역 선택.
- 다국어 라벨과 툴팁.
- macOS DMG 설치 패키지.

## 후보 버전

`v0.1.1-candidate`는 Apple Silicon macOS 14 이상을 대상으로 합니다.

GitHub Releases에서 DMG를 다운로드한 뒤 `xAlgo Explorer.app`을 `Applications`로 드래그하세요.

## 버전 노트

### v0.1.1-candidate

- 취소된 내부 드래그의 오래된 payload가 남아 이후 드롭에서 잘못된 파일을 이동할 수 있는 문제를 수정했습니다.
- `../file` 또는 `a/b` 같은 안전하지 않은 이름 변경 입력을 거부하도록 검증을 추가했습니다.
- 잘라낸 파일을 원래 폴더에 다시 붙여넣으면 중복 이름을 만들지 않고 no-op 처리합니다.
- Finder와 함께 사용할 수 있는 시스템 클립보드 기반 파일 URL 복사/붙여넣기를 추가했습니다.
- 검색 닫기 버튼과 Escape 처리를 추가해 포커스를 해제한 뒤 방향키로 파일 목록을 다시 탐색할 수 있게 했습니다.
- 하드코딩된 가짜 네트워크 장치를 제거하고 실제 탐지가 구현되기 전까지 빈 네트워크 상태를 표시합니다.
- 후보 버전 메타데이터, DMG 이름, README, 회귀 테스트를 업데이트했습니다.

### v0.1.0-candidate

macOS 네이티브 파일 관리자 셸, 멀티 패널 탐색, 드래그 앤 드롭 파일 작업, 키보드 탐색, 다국어 툴팁, Apple Silicon용 서명된 DMG 패키징을 포함한 첫 공개 후보 버전입니다.
