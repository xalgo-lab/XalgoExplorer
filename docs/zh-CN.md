# XalgoExplorer

XalgoExplorer 是一款 macOS 原生文件管理器，重点面向从 Windows 切换到 macOS 的用户。

它的目标不是复制 Finder，也不是做复杂的云端文件工具，而是帮助 Windows 用户在 macOS 上更快恢复熟悉的文件操作习惯。

## 主要特点

- 多窗口工作区，方便同时查看多个目录。
- 熟悉的工具栏操作：返回、前进、上一级、刷新、新建文件夹、新建文件、剪切、复制、粘贴。
- 拖拽逻辑接近 Finder：同磁盘默认移动，不同磁盘默认复制。
- 左侧紧凑图标栏，支持常用目录、用户快捷方式、挂载磁盘和网络位置。
- 支持键盘方向键选择、鼠标点选和区域选择。
- 多语言界面标签和鼠标悬停提示。
- 支持打包为 macOS DMG 安装包。

## 候选版本

`0.1.0-candidate` 面向 Apple Silicon macOS 14 或更高版本。

在 GitHub Releases 下载 DMG，打开后将 `xAlgo Explorer.app` 拖入 `Applications` 即可。
